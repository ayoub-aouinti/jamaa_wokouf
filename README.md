# جامع الوقوف — التطبيقات

فوق قاعدة Postgres التي تبنيها `db/migrate.py` ثلاثةُ تطبيقات في مستودعٍ واحد
(npm workspaces). وقانونُ المشروع في `CLAUDE.md` يسري عليها كلِّها.

```
apps/api       الواجهة البرمجية — NestJS 12 فوق Postgres (pg بلا ORM)
apps/web       الويب — React 19 + Vite. وهو تطبيقُ سطح المكتب أيضاً
apps/mobile    الجوال — Expo SDK 57 + Expo Router
packages/shared  الأنواعُ ورموزُ التصميم وعميلُ الواجهة، للويب والجوال
db/app_schema.sql  سجلُّ المراجعة — إضافةٌ لا تمسّ db/schema.sql
```

**ليس للجامع تطبيقُ سطح مكتبٍ منفصل.** واجهةُ الويب قابلةٌ للتثبيت من
المتصفّح (Chrome أو Edge: «تثبيت» في شريط العنوان)، فتعمل في نافذتها
مربوطةً بالخادم.

## التشغيل

يلزم Node 20.19 فما فوق.

```bash
npm install

# ١- الاتصالُ بالقاعدة
cp apps/api/.env.example apps/api/.env      # واملأ DATABASE_URL و ADMIN_TOKENS

# ٢- القاعدةُ والبيانات (مرّةً واحدة)
npm run db:create                                  # يُنشئ القاعدةَ المسمّاة في DATABASE_URL إن غابت
pip install -r requirements.txt
python db/migrate.py out/waqf.db "<DATABASE_URL>"  # ينقل الأحكامَ من SQLite ويتحقَّق من العدد
npm run db:app                                     # سجلُّ المراجعة، ويُعاد بلا ضرر
npm run db:check                                   # يسرد قواعدَ الخادم وأيُّها فيه الجامع

# ٣- الخادمُ والويب، كلٌّ في طرفيّة
npm run api        # http://localhost:3000/api
npm run web        # http://localhost:5173  (يُمرِّر /api إلى الخادم)

# ٤- الجوال
npm run mobile     # ثم امسح الرمز بـ Expo Go
```

**تنبيه في تثبيت حزم الجوال:** بعد `npx expo install <حزمة>` داخل `apps/mobile`
شغِّل `npm install` من جذر المستودع. فإن بقيت الحزمةُ في
`apps/mobile/node_modules` لم يجدها `expo start` (خطأ `Cannot find module
'expo-router/...'`)، والعلاجُ حذفُ `node_modules` و`package-lock.json` ثم
`npm install` من الجذر.

يجد الجوالُ الخادمَ تلقائياً على عنوان الجهاز الذي يُشغِّل Metro، منفذ 3000.
فإن كان الخادمُ في مكانٍ آخر فعرِّف `EXPO_PUBLIC_API_URL`.

```bash
npm run build      # الواجهة البرمجية (tsc) والويب (vite)
npm run typecheck  # كلُّ الحزم
npm test           # اختباراتُ الواجهة البرمجية (بعد build)
```

## الواجهة البرمجية

القراءةُ كلُّها مفتوحة. والكتابةُ برمز مراجِعٍ (`Authorization: Bearer …`)
من `ADMIN_TOKENS`، وكلُّ كتابةٍ تُقيَّد في `review_log` بقيمتها قبلُ وبعدُ.
فإن لم يُعرَّف رمزٌ أُغلقت الكتابة، وإن لم يُطبَّق `app_schema.sql` رُفضت.

| الطريق | ما يُرجِع |
|---|---|
| `GET /api/sources` | المصادرُ وعددُ أحكام كلٍّ بحالها، وحالُ المصدر، وتنبيهاتُ نسخته |
| `GET /api/categories` · `/suras` · `/riwayat` · `/stats` | الفئات، السور، الروايات، الإحصاء |
| `GET /api/suras/:sura/ayat?from=&to=` | آياتٌ بكلماتها وأحكامِ مصادرها موجَزةً، وما قبلها وما بعدها |
| `GET /api/words/:seq` | تفصيلُ الموضع: الأحكامُ كاملةً بعللها، والمصادرُ الساكتة، ومقابِلُه في الروايات |
| `GET /api/riwayat/:id/text?sura=&from=&to=` | نصُّ روايةٍ لنطاقٍ من فهرس حفص |
| `GET /api/search?q=` | بحثٌ بعد إسقاط الضبط، والعبارةُ كلماتٌ متتالية |
| `GET /api/terms` · `PATCH /api/terms/:source/:symbol` | جدولُ المصطلحات، وضبطُ `reviewed` و`category` و`approx` |
| `GET /api/review/queue` · `POST /api/review/:seq/:source` | طابورُ المقترَح، وقرارُ `verify` أو `reject` |

### كيف يحفظ التطبيقُ القانون

- **اللفظُ قبل الفئة.** يُعرَض `raw` بعينه أوّلاً، والفئةُ شارةُ لونٍ عليها ≈
  إن كانت تقريبية. ولا يُحسَب في أيِّ شاشةٍ اتفاقٌ ولا خلافٌ من الفئات، ولونُ
  خطِّ الكلمة في القارئ محايدٌ ما لم يختر القارئُ مصدراً يُلوَّن بفئته.
- **المقترَحُ يُسمّى مقترَحاً** بإطارٍ أحمرَ متقطِّع، وحالُ كلِّ مصدرٍ ظاهرٌ في
  القارئ وفي صفحة المصادر.
- **الخلوُّ ليس نفياً.** تفصيلُ الموضع يذكر المصادرَ الساكتة، ويُنبِّه إن كان
  الموضعُ خارجَ حدود نسخة المصدر.
- **العلّةُ كاملة** في تفصيل الموضع، لا تُقطَع ولا تُلخَّص.
- **الردُّ لا يحذف.** «ارفض» يُبقي الحكمَ مقترَحاً ويُضيف سببَ الردِّ إلى
  `review` بعد ما فيه. و«اعتمد» يرفعه إلى `verified`.
- **ضبطُ المصطلح لا يمسّ الأحكام.** `PATCH /terms` يعدِّل جدولَ المقابلة وحده.

## ما ينقص

- **خطوطُ المصاحف.** نصُّ ورش وقالون في القاعدة مرمَّزٌ لخطِّ المصحف المغربي
  الذي بُنيت عليه لوحاتُ التصميم، فبغيره تظهر بعضُ الحروف رموزاً. تُوضَع
  الملفّاتُ في `apps/web/public/fonts/` (انظر README فيها).
- **صفحاتُ المصحف.** لا رقمَ صفحةٍ في `words`، فالقارئُ يقسم السورةَ نطاقاتٍ
  بنحو ١٥٠ كلمة، لا صفحاتِ المطبوع.
- **الجوالُ بحفصٍ وحده** في القارئ، والرواياتُ الأخرى تظهر في تفصيل الموضع.
- **المراجعةُ في الويب وحده.** الجوالُ للقراءة.
